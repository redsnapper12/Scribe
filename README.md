# Scribe
A lightweight, open-source virtual tabletop for D&D 5e remote gaming built in Godot 4.5.1 with C#.

## What is Scribe?
Scribe is a tool for running D&D 5e games remotely, not a video game. It handles character sheets, dice rolling, and 2D battlemaps to facilitate tabletop gaming sessions over the internet. The project emphasizes flexibility and ease of modification, allowing game masters and players to create and customize content without writing code.

## Key Features
- Turn-Based Combat System: Full D&D 5e combat with initiative tracking, movement budgets, and victory conditions
- Grid-Based Movement: 64x64 pixel cells representing 5-foot D&D squares with terrain costs and pathfinding
- Character Management: Data-driven character creation using Godot's inspector interface
- DM Tools: Dungeon Master controls for managing combat, entities, and campaign state
- Component-Based Architecture: Flexible entity system that avoids rigid inheritance hierarchies

## Why choose Scribe over other online VTTs?
Scribe is designed to be accessible, transparent, and modifiable to its users. No subscription, no fee, yet still feature rich. Create as many custom characters, classes, races, monsters, items, as your harddrive desires! No payment for extra features, Scribe is developed by a D&D player, for other D&D players!
